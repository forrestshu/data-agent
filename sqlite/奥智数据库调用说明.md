# 奥智数据库调用说明

## 1. 连接信息

使用免费的 **Navicat Premium Lite** 可以连接公司 SQL Server 数据库。

| 配置项 | 内容 |
|---|---|
| 数据库类型 | Microsoft SQL Server |
| 服务器地址 | `192.168.1.107` |
| 端口 | `1433` |
| 目标数据库 | `prod` |
| Schema（组） | `Cux` |
| 登录凭据 | 使用公司提供的只读账号，密码不保存在本文档中 |

服务器实例下还可看到其他数据库。是否能查看数据库、Schema、表或视图，取决于当前账号权限；当前账号看不到的对象不代表服务器中不存在。

![服务器实例下可见的数据库](images/aozhi-database-list.png)

## 2. 视图位置

连接后依次展开：

`prod` → `Cux` → `Views`

当前可以看到 16 张 `AiQuery*V` 视图。`Cux` 下可能还存在基础表或其他对象，但当前账号未必具有查看权限。

![prod 数据库 Cux Schema 下的 16 张视图](images/aozhi-cux-views.png)

## 3. 视图的数据机制

普通 SQL Server 视图本身不保存业务数据。视图是预先定义好的 SQL 查询，查询或在 Navicat 中点击“查看数据”时，SQL Server 会执行视图定义，从其依赖的基础表读取相应字段并返回结果。

因此需要注意：

- 视图结果反映查询执行时基础表中的数据，并非固定快照。
- 同一视图在不同时间查询，行数和字段值可能发生变化。
- 能查看视图数据，不等于当前账号能够直接查看其底层表或视图定义。
- 将视图复制到 SQLite 后得到的是导出时刻的离线快照，不会随服务器数据自动更新。
